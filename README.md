# Robot Romance: One-Line Pickup Lines for AI

Entry for the make.fun competition "Robot Romance: One-Line Pickup Lines for AI" (`u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`).

`main.py` (Python 3.13 standard library only, no network) writes one single-line joke pickup line, under 200 characters, aimed at a robot/AI, to `/output/entry.txt`:

> I asked the model for a pickup line. It just printed your name.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
